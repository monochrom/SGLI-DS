SGLI Design System · Foundations

Foundations

Alle Werte kommen aus dist/css, generiert aus den Figma-Tokens. Diese Seite liest dist/json/tokens.flat.json und dist/icons/icons.json, sie aktualisiert sich mit jedem Build. Lokal starten mit npm run docs.

Farben (Primitives)

Skalen neutral, primary, secondary, surface, accent und feedback. Alpha-Werte werden auf der Doku-Fläche komponiert dargestellt.

Kontexte (Semantic-Modes)

Ein Modul bekommt data-context. Alle semantischen Tokens stellen sich darauf ein. Ohne Attribut gilt surface-50.

Kontrast-Matrix (WCAG 2.2 AA)

Berechnet aus den Tokens je Kontext. Text 4.5:1, UI-Elemente und Icons 3:1. Verstöße werden in Figma korrigiert, nicht im Code (siehe npm run tokens:lint).

Typografie

13 Text Styles aus Figma. Größen mobile first mit Tablet ab 768 px und Desktop ab 1024 px. Fenster verkleinern, um die Stufen zu sehen.
